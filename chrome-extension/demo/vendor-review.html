Vendor Security Assessment

A demo portal page for trying the attestq extension. Run attestq serve --demo --offline, serve this folder (python -m http.server 8080 -d chrome-extension/demo), open http://localhost:8080/vendor-review.html, choose helios and click Scan & Answer.

Engagement details

1. Identity & Access

1.1 Is multi-factor authentication enforced for remote and privileged access?
1.2 Are access rights granted on least privilege and reviewed periodically?

2. Data Protection

2.1 Is customer data encrypted in transit and at rest using industry-standard algorithms? Supporting details

3. Operations

# Control Response Vendor comments
3.1 Does the vendor run regular vulnerability scanning with defined remediation SLAs?
3.2 Does the vendor maintain and test business continuity and disaster recovery plans?
3.3 Does the vendor centralize security event logs and define explicit log-retention periods?

4. Incident Response

4.2 How does the vendor assess the security of its own subcontractors and fourth parties?
